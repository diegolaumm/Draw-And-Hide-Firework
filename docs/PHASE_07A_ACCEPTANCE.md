# Phase 07A — Artist's Canvas GUI Redesign 人工實機驗收指南

**狀態**：**PARTIAL — Awaiting User Visual Acceptance & Codex Review**

本文件提供 Phase 07A「羊皮紙畫布主題與工具列簡化（Artist's Canvas GUI Redesign）」之視覺與互動改造概述，以及最短實機驗收步驟。

---

## 一、核心改造重點

1. **羊皮紙畫布與木質畫框（Parchment Canvas & Wooden Easel Frame）**：
   - 中央繪圖區改為暖米白色／淡羊皮紙色微格紋底色（`#EFE3C6` 與 `#E2D3B1`），取代原本冰冷的灰色方塊（`#707070`）。
   - 外圍加入多層次淺木色與胡桃木深棕陰影畫框（含外框深棕邊、左上受光木紋高光、右下陰影、內嵌凹槽與四角銅釘點綴），且**嚴格繪製於可互動畫布區域外側**，絕不壓住任何可繪製像素或影響滑鼠落點。
   - **嚴格分離視覺底色與實際 ARGB 資料**：羊皮紙僅作為 GUI 渲染背景，`FreehandCanvas` 內部的透明像素（`0x00000000`）、純白（`#FFFFFF`）、淡黃（`#FFDF40`）與所有顏色 100% 保持原樣，絕不將羊皮紙色寫入圖稿或煙火資料。

2. **右側工具列精簡與圖示化（8 列緊湊畫家工具面板）**：
   - 由原本擁擠的 10 列純文字按鈕，重組為 **8 列視覺分組面板**（附亞麻木質底板與細分隔線）：
     - **調色盤區（Row 1–2）**：2×4 緊湊色彩方塊（無冗長文字），選中時具雙層明亮金框與角落指示點。
     - **筆刷粗細滑桿（Row 3）**：保留清楚的數值顯示與滑鼠拖曳。
     - **繪圖工具列（Row 4）**：新增獨立【畫筆（Brush）】按鈕，與【橡皮擦（Eraser）】、【油漆桶填色（Fill）】並排為 3 顆純圖示按鈕。
     - **歷史操作列（Row 5）**：【復原（Undo）】与【重做（Redo）】左／右彎箭頭純圖示按鈕，並支援無歷史時自動呈現 Disabled 停用暗化狀態。
     - **檢視與轉換列（Row 6）**：【柔和/銳利（Mode）】與【繪圖/32×32/粒子（View）】圖示＋簡短狀態文字切換鍵。
     - **草稿管理列（Row 7）**：柔和藍綠色系【草稿庫（資料夾圖示）】與【存稿（磁碟片圖示）】。當畫布有未儲存變更時，存稿鈕自動亮起金色描邊提醒。
     - **離開與煙火輸出列（Row 8）**：左側小型暗紅【關閉（X 圖示）】按鈕，右側醒目暖金色【轉為煙火（煙火火箭圖示＋文字）】主行動按鈕。
   - **完整 Hover Tooltip**：所有色塊與工具按鈕在滑鼠懸停時均顯示完整中／英文名稱與快捷鍵說明。

3. **相關草稿畫面風格統一**：
   - `DraftManagerScreen`、`DraftListWidget`、`DraftNamePromptScreen`、`UnsavedChangesScreen` 同步套用暖棕畫室背景與羊皮紙奶油白／金色標題配色，所有草稿工作流程與安全防護邏輯 100% 不變。

## 二、最短實機驗收步驟（9 項檢查）

### 啟動遊戲
```powershell
Set-Location D:\minecraftmod
$env:GRADLE_USER_HOME='D:\minecraftmod\gradle'
.\gradlew.bat runClient
```
進入單人創造模式世界，主手持有 `drawfirework:test_firework`，按 **G** 開啟畫布編輯器。

### 檢查清單

1. **羊皮紙畫布與木框視覺氛圍**：
   - 確認中央畫布呈現溫暖的羊皮紙微格紋質感，外圍包覆立體木質畫框，整體背景為暖棕畫室色調，不再是單調灰色方塊。
2. **右側工具列簡潔度**：
   - 確認右側面板已收納為整齊的色塊、圖示與分組區塊，文字按鈕大幅減少，視覺焦點集中於中央畫布。
3. **Hover Tooltip 提示**：
   - 將滑鼠依序停留在調色盤色塊、畫筆、橡皮擦、填色、Undo、Redo、模式、檢視、草稿庫、存稿、關閉與轉為煙火按鈕上，確認皆能正常顯示中／英文功能與快捷鍵 Tooltip。
4. **Selected / Unselected / Disabled 狀態辨識**：
   - 點擊切換不同顏色、畫筆、橡皮擦、填色：確認目前選中項目有明顯金色亮框。
   - 剛開啟空白畫布尚未繪圖時：確認 Undo 與 Redo 按鈕呈現暗化停用（Disabled）狀態；畫一筆後 Undo 自動亮起可用，按 Undo 後 Redo 自動亮起可用。
5. **繪圖工具操作與邊界精準度**：
   - 使用畫筆、橡皮擦、油漆桶填色、Undo/Redo 操作，並嘗試在畫布最左上角、最右下角及木框邊緣點擊，確認木框不會遮擋畫布像素，且點擊木框不會誤畫到畫布。
6. **透明底色與白色／淡黃色筆畫辨識**：
   - 選取**白色**與**黃色**在羊皮紙畫布上繪畫，確認筆畫與羊皮紙微格紋底色可清楚分辨；使用橡皮擦擦除後恢復為羊皮紙透明底格紋。
7. **32×32 預覽與煙火粒子預覽**：
   - 點擊檢視切換按鈕（或按 `P`）切換至 `32×32` 與 `粒子（Dust）` 預覽，確認預覽背景（羊皮紙格紋／夜空漸層）與粒子統計資訊正常，且透明區不會變成米黃色粒子。
8. **Save Draft 與 To Firework 語意區隔及草稿庫流程**：
   - 確認藍綠色【存稿（磁碟片）】與暖金色【轉為煙火（火箭）】外觀與位置截然不同。
   - 測試存稿、開啟【草稿庫】載入／新建／刪除確認，以及點擊【轉為煙火】後在世界右鍵發射煙火，確認空中的五階段 76 ticks 煙火動畫正常且透明背景無雜點。
9. **一般視窗與縮小視窗響應式排版**：
   - 調整遊戲視窗大小或切換 GUI Scale，確認木框、畫布、底部統計文字與右側工具列無重疊、無裁切且按鈕均可正常點擊。
